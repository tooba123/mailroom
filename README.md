# mailroom

A Python project managed with [uv](https://docs.astral.sh/uv/).

## Requirements

- Python 3.12 or newer
- [uv](https://docs.astral.sh/uv/)

## Setup

```bash
uv sync
```

## Usage

```bash
uv run mailroom
```

## Development

```bash
uv run pytest
uv run ruff check .
uv run ruff format .
```
